# EduCam True/False

Game edukasi berbasis kamera dengan soal manual dan penyimpanan data ke browser (`localStorage`).

## Fitur
- Kamera aktif untuk permainan
- Soal manual dapat ditambah, diubah, dan dihapus
- Soal tersimpan otomatis di browser menggunakan `localStorage`
- Mode game benar/salah dengan timer
- UI pengaturan waktu dan pendiktean

## Cara pakai
1. Buka file `index.html` di browser.
2. Masuk ke tab `Kelola Soal`.
3. Tambahkan soal, lalu klik `Simpan Soal`.
4. Refresh halaman, soal akan tetap ada.

## Catatan
Penyimpanan ini berlaku per browser/perangkat, bukan database pusat.
